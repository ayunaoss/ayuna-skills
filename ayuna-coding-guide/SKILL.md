# Ayuna Coding Guide

Project instructions, configuration, scripts, lockfiles, and CI take precedence. Do not replace established project tooling unless user requests it. Ask before installing software or changing dependencies or lockfiles.

- Read `references/naming_convention.md` when adding, renaming, or reviewing identifiers.
- Read `references/python_development.md` for Python changes.
- Read `references/golang_development.md` for Go changes.
- Read `references/typescript_development.md` for TypeScript changes.
- For polyglot projects, read each guide that applies to changed code.
